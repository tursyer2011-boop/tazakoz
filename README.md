# TAZA KÖZ — Lovable Build Prompt

## Общая идея

Приложение для мониторинга загрязнения водоёмов Казахстана. Пользователи фотографируют загрязнения, ИИ проверяет подлинность и масштаб, данные попадают на карту. Дизайн лёгкий, минималистичный, тёмная тема (сине-бирюзовая палитра под лого).

---

## 1. ОНБОРДИНГ / РЕГИСТРАЦИЯ (первый экран)

При первом открытии — экран регистрации, доступ к функциям только после входа.

- Логотип TAZA KÖZ + слоган "Kör. Habarla. Qorğa."

- Кнопка "Войти через Google" (Supabase Auth Google OAuth)

- Кнопка "Войти через Apple" (Supabase Auth Apple OAuth)

- Разделитель "или"

- Поля Email + пароль, кнопка "Зарегистрироваться"

- Ссылка "Уже есть аккаунт? Войти"

- При регистрации дополнительно спросить: ФИО (реальное), номер телефона, город/область (dropdown: Астана, Алматы, Атырау, Актау, Шымкент, Түркістан, Орал, и т.д.)

- После входа — редирект на главный экран (карта)

---

## 2. НИЖНЯЯ НАВИГАЦИЯ (bottom nav, как в TikTok)

5 иконок:

1. **Главная** (домик) — карта загрязнений

2. **Рейтинг** (кубок/список) — топ пользователей по кредитам

3. **Камера** (по центру, крупная кнопка, выделена цветом) — отправить жалобу

4. **Погода/вода** (капля) — температура и данные водоёмов по региону

5. **Профиль** (аватар) — баланс кредитов, история заявок, настройки

---

## 3. ЭКРАН "ГЛАВНАЯ" — Карта

- Карта Казахстана (или 2GIS/Google Maps integration) с маркерами загрязнений

- Маркеры цветные по степени: 🟢 зелёный (слабое) / 🟡 жёлтый (среднее) / 🔴 красный (сильное)

- Фильтр сверху: по региону, по статусу (новое/в работе/убрано)

- Тап на маркер → карточка: фото, комментарий, статус, дата

---

## 4. ЭКРАН "ОТПРАВИТЬ ЖАЛОБУ" (камера)

Шаги:

1. Сделать фото или загрузить из галереи

2. Автоматически подтягивается геолокация (с возможностью скорректировать на карте)

3. Поле комментария (текст)

4. Кнопка "Отправить"

5. Показывается лоадер "ИИ проверяет фото..."

6. Результат: принято (с оценкой масштаба) или отклонено (с причиной)

**Backend-логика (Claude Vision API):**

- Промпт для проверки: (1) является ли фото реальной фотографией (не AI-сгенерировано, не скриншот, не фотошоп), (2) содержит ли признаки загрязнения воды/берега (мутная/тёмная вода, мусор, мёртвая рыба, пластик, нефтепродукты), (3) присвоить масштаб: слабое/среднее/сильное по чётким критериям (площадь загрязнения, кол-во мусора, признаки вреда экосистеме)

- Если фото не проходит проверку — жалоба отклоняется, засчитывается в статистику пользователя (для анти-фрод системы)

---

## 5. ЭКРАН "ПОГОДА / ВОДА"

- Выбор региона/водоёма

- Температура воды (если данных нет — placeholder "Скоро")

- Общий прогноз погоды (через открытое API)

- Список последних замеров по водоёму

---

## 6. ЭКРАН "РЕЙТИНГ"

- Список пользователей, сортировка по максимально накопленным кредитам (не по остатку)

- ФИО + город + кредиты + бейдж (кол-во подтверждённых жалоб)

- Свой рейтинг закреплён сверху

---

## 7. ЭКРАН "ПРОФИЛЬ"

- Аватар, ФИО, город

- Баланс кредитов (текущий остаток)

- Максимально накоплено (для рейтинга)

- История заявок со статусами

- Кнопка "Выйти"

---

## Технологии

- Frontend: Lovable (React + Tailwind)

- Auth + DB: Supabase (users, reports, credits tables)

- AI-проверка фото: Claude Vision API

- Карта: 2GIS API или Google Maps Embed

- Погода: OpenWeather API

## Дизайн

- Тёмный фон, акценты — бирюзовый/синий градиент (как в лого)

- Минимум текста, много иконок, крупные кнопки

- Шрифт — чистый sans-serif, без засечек

- Иконки — outline-стиль, единая толщина линий
